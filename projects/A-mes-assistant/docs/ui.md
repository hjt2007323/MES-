# 页面与演示

- 页面默认“自然语言问答”，可切到保留的“命名查询”入口。
- 自然语言页：问题、参考时间、运行模式（默认 mock）、预算、提交。
  - mock 不联网、不访问 DB、不需要 key。
  - 只有表单提交调用一次；普通 rerun 只重绘已存结果。
- 结果区显示状态、数据版本、review_status、演示口径、context_mode、最终 plan、
  答案/表/空表提示/SQL/trace；NULL 显示“未知”。
- 页面只绑定 `127.0.0.1:8501`；不自动启停数据库，不提供 SQL 编辑。
- 页面 HTTP 健康不是浏览器视觉验收；人工点击截图由演示者另行记录。
- 真实模型/数据库不在本候选的公开入口；既有真实证据不在候选目录内。
