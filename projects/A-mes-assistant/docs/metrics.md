# 演示口径与边界

数据为合成夹具，标识 `mes-a07-boundary-v1-pending`，`review_status=pending`。
已确认的是**演示工程口径**，不是企业真实数据或业务验收。

## 三个命名查询

- `line_snapshot`：按产线汇总工单当前累计实际量；包含所有产线和工单状态，
  无工单显示 0。单问“产量是多少”需要澄清范围；明确的日产量/工序产量超出目录。
- `work_order_progress`：按一条产线列工单；完成比 = 实际量 / 计划量，零计划为未知，
  超产比值保留，精度按数据库四位小数，原始状态原样展示。
- `downtime_details`：列出与窗口相交的原始停机事件；匹配
  `start < window_end AND (end IS NULL OR end > window_start)`；保留原始 NULL、
  重叠和异常边界记录，不计算停机分钟/并集。

## 安全边界

- 缺产线/时间窗或窗口反向时澄清；未知别名或多产线请求澄清；
  显式合法数值 ID 可查询，允许零行。
- “昨天”只按固定参考时间 `2026-11-02T00:00:00+08:00` 和
  `Asia/Shanghai` 解释。
- 库存、质检、写入、系统表、密钥等目录外请求拒绝。
- 模型不能产生/执行 SQL；查询只走命名工具，页面不提供 SQL 编辑。
- 不计算新指标，不写企业收益/准确率；空表和 NULL 不画成 0。
