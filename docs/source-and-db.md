# 来源、依赖与数据库边界

本候选是合成数据、离线优先的公开演示，**不是**企业生产系统或许可声明之外的再分发。
许可证为 MIT；第三方依赖与 MySQL 的边界见下。

## 候选来源

- 问答与录入代码：项目自有（A 编排/UI、B 语义/规划/存储、C 独立判定）；
- 合成数据与 fixture：项目自造，仅用于演示；
- 公开基线：`release/a07-github-v1` 的公开问答版本，M5 在其上增加停机录入；
- 候选逐文件来源、字节数与 SHA-256 见根目录 `candidate-manifest.json`。

## 依赖

- Python 标准库；UI 使用 Streamlit 1.66.1 及 `requirements-ui.lock.txt` 锁定依赖；
- 依赖从官方 PyPI 安装，不随候选分发源码；许可证以各包元数据为准；
- MySQL Community 8.0.28（GPLv2）**不进入候选**；历史真实问答测试使用外部只读 MySQL，
  不在本候选复现；
- 离线 CI 不安装/启动数据库，不调用真实模型。

## 数据库边界

- 问答：公开 mock 不访问数据库；历史 MySQL 结果属于既有证据，不在候选内。
- 录入：使用标准库 SQLite，默认路径为候选根 `runtime/a07-intake/downtime.sqlite3`
  （已加入 `.gitignore`），只存人工确认后的合成事件。
- 录入写入使用固定参数化 SQL、同键幂等与固定错误码；不迁移原 MySQL 历史异常。
- 真实数据库独立初始化不在本候选承诺内；候选不包含 MySQL 二进制、data、secrets 或日志。
